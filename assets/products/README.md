# Food and store product models

These source GLB models are from Kenney's **Food Kit** collection:
- Original pack: https://kenney.nl/assets/food-kit
- License: Creative Commons Zero 1.0 Universal (CC0); commercial use is permitted and attribution is not required.
- Source mirror used to transfer the original GLB files: https://github.com/Hidencod/tge-assets/tree/main/packs/food-kit

The `.glb.b64` files contain the original GLB bytes encoded as Base64 for runtime loading by Godot.
