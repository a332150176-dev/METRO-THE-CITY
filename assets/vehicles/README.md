# Vehicle model assets

The vehicle models in this folder are original GLB files from Kenney's **Car Kit**.

- Original asset pack: https://kenney.nl/assets/car-kit
- Publisher/download page: https://kenney-assets.itch.io/car-kit
- License: Creative Commons Zero 1.0 Universal (CC0); commercial use is permitted and attribution is not required.
- Source mirror used to transfer the original GLB files into this repository: https://github.com/Hidencod/tge-assets/tree/main/packs/car-kit

The `.glb.b64` files contain the original GLB bytes encoded as Base64. Godot decodes and imports them into reusable PackedScenes at runtime. Source models are not modified.
