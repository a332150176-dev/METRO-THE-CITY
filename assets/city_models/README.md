# City model assets

The `building-type-a` through `building-type-h` models are from Kenney's **City Kit (Suburban)**.

- Original pack: https://kenney.nl/assets/city-kit-suburban
- License: Creative Commons CC0 1.0 Universal (public domain dedication).
- Attribution is not required; credit is retained here for provenance.
- Source mirror used to transfer the original GLB files into this repository: https://github.com/Hidencod/tge-assets/tree/main/packs/city-kit-suburban

The `.glb.b64` files contain the original GLB bytes encoded as Base64 so they can be stored as text files and decoded at runtime by Godot. They are not modified models.
