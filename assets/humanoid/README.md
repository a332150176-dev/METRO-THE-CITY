# Rigged humanoid model kit

The body and modular outfit meshes in this folder are from the NoLimitNexus **game-models** project:
- Source: https://github.com/NoLimitNexus/game-models
- The project's README states that `library/ours` is its own mesh work, built by its included Blender kit generator.
- The two animation GLBs use Kay Lousberg's KayKit `Rig_Medium` animation set, identified in the source README as CC0.
- Source README and manifest are preserved at the source repository for provenance.

The body and clothing pieces share the same 23-joint `Rig_Medium` skeleton. The GLB data is stored Base64-encoded here for runtime import in Godot.
